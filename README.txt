RANDOM SPECIALS CATEGORY — BASIC WEB ŞABLONU

Dosyalar:
- index.html: Ana sayfa
- css/style.css: Görünüm
- js/script.js: JavaScript ve AJAX kodu
- data/categories.json: Kategoriler
- data/menu_items.json: Örnek ürünler

ÇALIŞTIRMA
1. ZIP dosyasını çıkart.
2. Bilgisayarda Python kuruluysa bu klasörde bir terminal aç.
3. Windows: py -m http.server 8000
   macOS/Linux: python3 -m http.server 8000
4. Tarayıcıda http://localhost:8000 adresine git.

Alternatif: VS Code içinden Live Server ile index.html sayfasını aç.
JSON dosyaları AJAX ile yüklendiğinden, index.html dosyasına doğrudan çift tıklamak bazı tarayıcılarda çalışmaz.

TEST
- Menü: Tüm kategorileri listeler.
- Specials: Rastgele seçilmiş tek bir kategorinin ürünlerini açar.
- Ana sayfaya dönüp Specials'a yeniden basarak başka bir kategori deneyebilirsin.

Bu örnekteki ürün ve fiyatlar tamamen örnek veridir.
